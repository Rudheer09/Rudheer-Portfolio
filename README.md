# Rudheer Kudupudi — Portfolio Website

A responsive, single-page personal portfolio created for the beginner-level UI/UX internship task.

## Checklist coverage
- Home / introduction section
- About section
- Skills / tools section
- Projects section
- Contact section with working email, LinkedIn, and GitHub links
- Responsive desktop, tablet, and mobile layout
- Consistent typography, spacing, colors, visual hierarchy, and interaction styling
- Mobile navigation menu, smooth anchor navigation, skip link, and reduced-motion support

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. For a local server, run `python -m http.server 8000` from this folder and open `http://localhost:8000`.

## Publish for a submission link
Upload the folder to GitHub and enable GitHub Pages, or drag the folder into a static hosting provider such as Netlify. Submit the deployed URL, not a local `file://` path.

## Before submitting
The project cards are clearly described as starter examples. Replace their descriptions with real completed work and update skills to reflect your current proficiency. Check all external profile URLs and the mail link once after deployment.
